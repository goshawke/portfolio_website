# Portfolio Website

Welcome to my portfolio website repository! This project showcases my skills, experiences, and projects in a clean and professional manner.

## 🚀 Project Overview

This repository contains the source code for my personal portfolio website, built using modern web development technologies. The website is designed to provide a comprehensive overview of my professional background, skills, and projects. It also includes links to my social media profiles and contact information.

## 🛠️ Features

- **Responsive Design**: The website is fully responsive, ensuring a great user experience on any device, whether it's a desktop, tablet, or mobile phone.
- **Dynamic Content**: The content is dynamically generated to ensure ease of updates and content management.
- **Smooth Animations**: Subtle animations enhance user interaction and provide a modern look and feel.
- **Interactive Project Showcase**: Projects are displayed with detailed descriptions, tech stacks, and links to GitHub repositories.
- **Contact Form**: A functional contact form that allows visitors to reach out to me directly from the website.

## 💻 Tech Stack

- **Frontend**: 
  - React.js: A JavaScript library for building user interfaces.
  - HTML5 & CSS3: Markup and styling.
  - JavaScript (ES6+): Core functionality.
  
- **Deployment**: 
  - GitHub Pages: Hosting the website directly from the repository.

## 📦 Installation

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/goshawke/portfolio_website.git

2. Navigate to the project directory:
  ```bash
  cd portfolio_website
  ```


4. Install the dependencies:
  ```bash
  npm install
  ```

6. Start the development server:
  ```bash
  npm start
  ```

5. Open your browser and visit http://localhost:3000 to view the website.

🚀 Deployment

The website is deployed using GitHub Pages. To deploy any updates:

1. Ensure all changes are committed and pushed to the main branch.
2. Run the following command to build the production version of the website:
  ```bash
  npm run build
```
3. Deploy to GitHub Pages:
  ```bash
  npm run deploy
```
